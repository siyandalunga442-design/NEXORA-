# NEXORA website — first release

A responsive static website built with HTML, CSS and a small amount of JavaScript. No build step is required.

## Preview locally
Open `index.html` in a modern browser.

## Before publishing
1. Replace `hello@nexora.example` in `index.html` with an email address you control.
2. Confirm that the project descriptions and development statuses are accurate.
3. If desired, add real social profile links and update the Open Graph metadata.

## Free deployment with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a **public** repository named `nexora-website`.
3. Upload all files in this folder to the repository's root (not the folder itself).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. After GitHub finishes publishing, the site will be available at `https://YOUR-USERNAME.github.io/nexora-website/`.

GitHub Pages may take a few minutes to publish the first time. The exact public URL depends on your GitHub username.
